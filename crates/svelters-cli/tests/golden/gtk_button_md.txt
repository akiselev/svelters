## Description
Calls a callback function when the button is clicked.

The `GtkButton` widget can hold any valid child widget. That is, it can hold
almost any other standard `GtkWidget`. The most commonly used child is the
`GtkLabel`.

## Properties
- `can-shrink`: `boolean`, rw, default `false`, bindable, since 4.12 — Whether the size of the button can be made smaller than the natural size of its contents.
- `child`: `Widget` or `null`, rw, bindable ⚠ dangerous — The child widget.
- `has-frame`: `boolean`, rw, default `true`, bindable — Whether the button has a frame.
- `icon-name`: `string` or `null`, rw, bindable — The name of the icon used to automatically populate the button.
- `label`: `string` or `null`, rw, bindable — Text of the label inside the button, if the button contains a label widget.
- `use-underline`: `boolean`, rw, default `false`, bindable — If set, an underline in the text indicates that the following character is to be used as mnemonic.
