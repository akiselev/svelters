# <main-window>.setCentralWidget · method
`qt main-window.method:setCentralWidget` · declared here · Site: /api/qt/main-window/#method-setcentralwidget

    void setCentralWidget(QWidget *widget)


> ⚠ **Dangerous: corrupts the widget tree.** Calling `setCentralWidget` is not possible from app code today; the backend owns this state. The central, menubar, statusbar, toolbars and docks slots are these calls (metadata/overrides/qt/QMainWindow.yaml:39-163); setCentralWidget/setMenuBar/setStatusBar also delete the widget they replace, which the renderer may still hold.
> **Use instead:** Children of <main-window> (default central slot; <menu-bar>, <status-bar>, <tool-bar parent:area>, <dock-widget parent:area>).
> Declared in `metadata/dangerous/qt.yaml#main-window-slots`. Nothing blocks it at run time yet.

Sets the given *widget* to be the main window's central widget.
