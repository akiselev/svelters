## Bundled packages

None. (Until RT1 a patched Svelte 5.57.2 tarball was vendored under `vendor/svelte/`; Svelte now comes from npm.)

npm and Cargo dependencies are not bundled in this repository. Each one is installed by its package manager under its own license.

`crates/svelters-egui` (OW4) depends on [quire-text](https://github.com/akiselev/quire) (`crates/quire-text`, MIT OR Apache-2.0) as a Cargo git dependency pinned by revision; its source is not copied into this repository. svelters' FX1 word rules (`native/words.rs`) and FX3 undo models (`native/undo.rs`) were moved into quire-text (with provenance lines there) and deleted here.

`crates/svelters-style` (CS0) depends on [cssparser](https://github.com/servo/rust-cssparser), [cssparser-color](https://github.com/servo/rust-cssparser) and [selectors](https://github.com/servo/stylo), which are MPL-2.0. MPL-2.0 is file-level copyleft: depending on these crates leaves svelters MIT, and none of their source (or lightningcss's or Stylo's) is copied into this repository.

## Toolkit metadata and documentation text

- **GTK** documentation text from GIR comments is LGPL-2.1-or-later. The generated docs site reproduces it with attribution; see the site page `/about/licensing/` (`docs/site/src/content/docs/about/licensing.md`).
- **Qt** documentation text is GFDL-1.3. The docs site reproduces only short briefs, with attribution and links to doc.qt.io. Qt's BSD-licensed snippets are not used.
- **`metadata/appkit/`** holds facts derived from the macOS SDK headers: class, property and method names, types, enum values and availability versions. It is generated with Xcode on macOS (Apple hardware, GitHub's macOS runner; currently Xcode 26.1.1, macOS 26.1 SDK) by `tools/metadata/appkit/ingest.py`, and CI regenerates and checks it. It contains no header text or documentation comments, and the SDK itself is not redistributed.
- **`metadata/winui/`** holds facts derived from the Windows App SDK `Microsoft.UI.Xaml.winmd`: names, types and attributes. The SDK packages are downloaded by `tools/metadata/winui/fetch.py` and are not redistributed.
